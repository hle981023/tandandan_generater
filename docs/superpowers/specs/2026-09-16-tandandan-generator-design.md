# 탄단단 이미지 & 글 제너레이터 설계

## 목표

탄단단 마케터가 브랜드 가이드를 매번 다시 해석하지 않고도 인스타그램용 이미지와 문구를 함께 만들고, 기존 문장을 탄단단다운 언어로 교정할 수 있는 로컬 웹앱을 만든다.

이번 버전은 배포하지 않는다. 로컬에서 완성된 화면과 전체 사용자 흐름을 확인할 수 있어야 하며, API 키가 없을 때는 데모 결과로 작동한다. 이후 API 키를 추가하면 실제 생성 모델로 전환할 수 있는 경계를 둔다.

## 사용자와 핵심 작업

- 사용자: 탄단단 내부 마케터
- 작업 1: 제품 이미지와 캠페인 정보를 넣고 인스타그램 무드 이미지, 온이미지 카피, 캡션, CTA를 함께 얻는다.
- 작업 2: 쓰고 싶은 원문을 넣고 탄단단 무드의 문장 3안과 가이드 검수 결과를 얻는다.

## 범위

### 포함

- 한 페이지 안의 두 작업 탭
- 제품 이미지 업로드와 미리보기
- Product, Ingredient, Culture 무드 선택
- 인스타그램 4:5 및 9:16 비율 선택
- 제품명, 제품 사실, 영양 수치, 사용 장면, 게시 목적 입력
- 이미지 결과 미리보기
- 온이미지 카피, 캡션, CTA 추천
- 원문을 탄단단 언어로 교정한 3개 결과
- 언어 가이드 체크리스트 및 경고 어휘 표시
- 복사, 결과 선택, 이미지 다운로드 인터랙션
- API 키가 없을 때 사용하는 구체적인 데모 결과
- 추후 실제 생성 API로 교체 가능한 서버 경계
- 데스크톱과 모바일 반응형 UI

### 제외

- 배포 및 도메인 연결
- 로그인과 권한 관리
- 데이터베이스 및 생성 이력
- 팀 공유와 승인 워크플로
- 인스타그램 직접 게시
- 결제 및 사용량 관리
- 여러 AI 제공자를 동시에 설정하는 관리자 화면

## 정보 구조와 흐름

상단에는 탄단단 흰색 가로 로고와 `TANDANDAN CREATIVE LAB` 표기를 둔다. 그 아래 두 탭을 배치한다.

### 이미지 & 글 생성기

1. 제품 이미지 업로드
2. 제품명, 제품 사실, 영양 수치 입력
3. 게시 목적과 사용 장면 입력
4. Product, Ingredient, Culture 중 무드 선택
5. 4:5 또는 9:16 선택
6. 생성 실행
7. 오른쪽 결과 영역에서 이미지와 문구를 함께 확인
8. 카피 또는 캡션을 선택하고 복사하거나 이미지를 다운로드

데스크톱에서는 왼쪽 입력 패널과 오른쪽 결과 캔버스를 동시에 보이게 한다. 모바일에서는 입력 다음에 결과가 이어지도록 한 열로 전환한다.

### 언어 교정기

1. 원문 입력
2. 문장의 사용 위치 선택: 온이미지, 캡션, CTA
3. 강조할 제품 사실과 사용 장면 입력
4. 교정 실행
5. 탄단단 버전 3안과 각각의 짧은 교정 근거 확인
6. 브랜드 적합성 체크와 경고 어휘 확인
7. 원하는 안을 복사

## 브랜드 규칙

### 언어

다음 다섯 항목을 결과 검수 기준으로 사용한다.

- 브랜드보다 소비자의 하루에서 시작하는가
- 가볍게 읽히는가
- 건강을 의무가 아닌 즐거운 루틴으로 말하는가
- 맛, 원료, 순간, 행동이 구체적인가
- 짧고 자연스러운 리듬이 있는가

권장 어휘에는 `리듬`, `루틴`, `밸런스`, `한 끼`, `가볍게`, `즐겁게`, `탄탄하게`, `나답게`, `매일`을 포함한다. `자격`, `가치`, `타협하지 않는`, `완벽한`, `본질`, `근원`, `견뎌내는`, `기준`은 경고 어휘로 표시한다. 제품 사실과 영양 수치는 사용자가 입력한 내용만 사용하며 임의로 만들지 않는다.

### 이미지

- Product: 제품과 패키지가 선명하게 보이는 고채도 구성
- Ingredient: 원물의 색과 형태를 크게 강조한 팝 그래픽
- Culture: 기록이나 성과보다 즐거운 움직임이 보이는 일상 장면

공통 시각 규칙은 높은 명도와 채도, 강한 자연광 또는 선명한 조명, 또렷한 그림자, 개방적인 공간, 강한 색 대비, 정적인 연출보다 움직임이 느껴지는 순간이다.

## 시각 디자인

- 기본 팔레트: 탄단단 오렌지 `#F15001`, 라임 `#E6FD93`, 딥그린 `#004A23`, 블랙, 화이트
- 영문 제목과 숫자: Elza Narrow
- 국문 및 본문: Pretendard
- 로고: 탄단단 공식 홈페이지의 공개 로고 에셋을 로컬 자산으로 저장해 사용
- 구성: 본 사이트의 강한 색면, 둥근 버튼, 굵은 타이포와 선명한 대비를 확장
- 인터페이스: 일반적인 회색 SaaS 대시보드가 아니라 캠페인 제작 테이블과 편집 캔버스가 결합된 모습
- 기억에 남는 요소: 결과 캔버스 주변에 비율 표식과 컬러 탭을 두어 브랜드 편집 보드처럼 보이게 한다.

Elza Narrow의 공식 웹폰트가 로컬에서 차단되면 일단 좁은 산세리프 대체 폰트로 동작하게 하고, 정확한 폰트 파일 또는 Adobe Fonts 사용 권한을 사용자에게 요청한다.

## 애플리케이션 구조

- UI: 단일 페이지 React 기반 로컬 앱
- 상태: 탭, 폼, 업로드 미리보기, 생성 상태, 선택된 결과만 클라이언트 상태로 관리
- 생성 경계: `/api/generate-image-copy`와 `/api/rewrite-copy` 두 엔드포인트
- 데모 모드: API 키가 없으면 입력 내용과 선택 무드에 맞춘 고정 규칙 기반 결과 반환
- 실제 모드: 추후 서버 환경 변수에 API 키를 넣으면 동일한 응답 구조로 텍스트와 이미지 생성 모델을 호출
- 저장: 이번 버전은 영구 저장하지 않으며 새로고침 시 초기화

응답 구조는 UI가 모델 제공자에 의존하지 않게 `image`, `headlineOptions`, `captionOptions`, `ctaOptions`, `checks`, `warnings`로 통일한다.

## 오류와 빈 상태

- 필수 입력이 없으면 해당 필드 아래에 짧은 오류 문구 표시
- 이미지 파일이 아닌 업로드는 즉시 거부
- 생성 중에는 결과 영역의 크기를 유지한 채 진행 상태 표시
- API 오류가 나면 입력을 보존하고 다시 시도 버튼 제공
- API 키가 없으면 오류 대신 명확한 데모 모드 배지 표시
- 제품 사실이 비어 있으면 수치나 효능을 임의 생성하지 않고 사실 입력을 요청

## 검증

- 두 탭의 전체 흐름을 데스크톱과 모바일에서 확인
- 이미지 업로드, 비율 변경, 생성, 결과 선택, 복사, 다운로드 확인
- 원문 교정 결과 3안과 체크리스트 표시 확인
- 권장 및 경고 어휘 검출 확인
- 입력하지 않은 영양 수치가 출력되지 않는지 확인
- 긴 한국어 문장과 긴 제품명에서 레이아웃이 깨지지 않는지 확인
- 키보드만으로 탭과 폼, 결과 버튼을 사용할 수 있는지 확인
- 로컬 프로덕션 빌드가 성공하는지 확인

## 완료 기준

- 첫 화면에서 마케터가 설명을 읽지 않고도 두 생성기 중 하나를 바로 사용할 수 있다.
- 탄단단 공식 사이트의 부속 도구로 인식될 만큼 로고, 컬러, 타이포, 버튼 인상이 연결된다.
- 데모 모드에서도 모든 주요 인터랙션이 끝까지 작동한다.
- 실제 생성 API를 붙일 때 UI를 다시 설계하지 않아도 된다.
